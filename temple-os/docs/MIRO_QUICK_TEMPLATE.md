## HOW TO USE IN MIRO:

1. Create 7 FRAMES for temple sections:
   - Outer Court (Blue)
   - Inner Court (Green)
   - Priests (Yellow)
   - Sanctuary (Purple)
   - Ark (Red)
   - River (Teal)
   - Memory (Orange)

2. Add cards above to each frame

3. Draw ARROWS showing data flow

4. Add STICKY NOTES for:
   - User journeys
   - Edge cases
   - Open questions

5. Use SHAPES for:
   - Database (cylinder)
   - External APIs (cloud)
   - Users (person icon)

6. Keep "7 Questions" card ALWAYS VISIBLE
