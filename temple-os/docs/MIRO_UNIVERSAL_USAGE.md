1. Open Miro → New Board
2. Name it: "[Your App Name] - Universal Spec"
3. Press **F** to create frames

## 🎨 VISUAL TIPS

### **Color Coding in Miro:**
- Red frames/sticky notes → Concept/Planning
- Blue → Architecture
- Green → Data/Backend
- Yellow → UI/UX
- Purple → Features
- Orange → Quality/Testing
- Teal → Launch/Deploy

### **Sticky Note Tips:**
- Yellow sticky = To-do
- Green sticky = Completed
- Pink sticky = Question/Blocker
- Blue sticky = Idea/Note

### **Use Icons:**
Search for these in Miro:
- 🏛️ Temple (for title)
- 👤 User (for personas)
- 🎨 Palette (for design)
- 🔐 Lock (for security)
- 📊 Chart (for data)

**For Working in Miro:**

- **S** = Shape
- **/** = Search tools
- **Cmd/Ctrl + D** = Duplicate

## 💡 PRO TIPS

### **Tip 1: Start Small**
Don't fill EVERY section perfectly.
Get the basics done, generate prompts, iterate.

### **Tip 2: Use Templates**
After first app, save your Miro board as template.
Next app? Duplicate, update, done faster.

### **Tip 3: Collaborate**
Invite team to Miro.
Fill out together.
Better ideas, more buy-in.

### **Tip 4: Take Breaks**
Miro auto-saves.
Fill out Concept + Temple today.
Data + UI tomorrow.
Features + Launch next day.

### **Tip 5: Export Progress**
Take screenshots at each stage.
Export as PDF when done.
Share with stakeholders.

## ❓ FAQ

**Q: Do I need to use Option A or B?**
A: Option A (30 min) for quick MVPs. Option B (2-4 hrs) for production apps.

**Q: Can I mix approaches?**
A: Yes! Start with Option A, then expand to Option B as needed.

**Q: What if I don't know an answer?**
A: Put "TBD" and come back. Or skip and iterate later.

**Q: Can I customize the structure?**
A: Absolutely! Add frames, remove sections, adapt to your needs.

**Q: How do I share with my team?**
A: Miro → Share → Invite by email or generate link.

**Q: Can I use on mobile?**
A: Miro mobile app works for viewing/commenting. Use desktop for setup.
